 # Problem Statement

## Project Title

Personal Finance Management System

## Problem Description

Managing personal finances manually can be difficult because income, expenses, budgets, and transactions may be recorded in different places. This can make it difficult for users to understand their spending habits and monitor their available money.

The Personal Finance Management System is developed to provide a simple console-based solution for recording and managing personal financial information.

## Objectives

- To record income details.
- To record expense details.
- To manage personal budgets.
- To view transaction information.
- To generate financial reports.
- To reduce manual financial record keeping.
- To provide a simple and user-friendly menu-driven system.

## Scope

The system focuses on basic personal finance management through a Java console application.

The scope includes:

- Income management
- Expense management
- Transaction management
- Budget management
- Report generation
- Input validation

The project does not currently include online banking integration, payment processing, or a graphical user interface.

## Target Users

The target users are:

- Students
- Working professionals
- Individuals who want to track personal income and expenses
- Users who want to monitor their monthly budgets

## High-Level Features

### 1. Income Management

Users can enter and store income details such as income ID, source, category, amount, date, and description.

### 2. Expense Management

Users can record expenses with details such as expense ID, category, amount, date, description, and payment method.

### 3. Transaction Management

Users can view and manage recorded financial transactions using transaction IDs.

### 4. Budget Management

Users can create or manage budgets by entering a budget ID, category, and budget limit.

### 5. Report Generation

Users can select report options to view financial information and summaries.

### 6. Input Validation

The system checks user inputs to reduce invalid entries and improve reliability.

## Expected Outcome

The expected outcome is a functional Java console application that allows users to record income and expenses, manage budgets, view transactions, and generate financial reports in an organized manner.
