  
  # Personal Finance Management System

## Overview

The Personal Finance Management System is a Java console-based application that helps users manage their personal income, expenses, budgets, transactions, and financial reports.

The system provides a simple menu-driven interface for recording financial information and viewing financial details.

## Features

- Add income records
- Add expense records
- View transaction details
- Manage budgets
- Generate financial reports
- Validate user inputs
- Store and manage financial records

## Technologies Used

- Java
- Object-Oriented Programming
- Java Collections
- File Handling
- Visual Studio Code
- Command Prompt / PowerShell
